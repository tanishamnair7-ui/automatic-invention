# Logo File Required

Please save your Hormona logo as `hormona-logo.png` in this directory.

The logo should be:
- Filename: `hormona-logo.png`
- Size: Square format (e.g., 200x200px or larger)
- Format: PNG with transparent background (preferred) or JPG

The logo will appear in the sidebar at 40x40 pixels.

Alternatively, you can use a different filename - just update the `src` prop in `/components/sidebar.tsx` (line 37) to match your filename.
